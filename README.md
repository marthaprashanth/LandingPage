# Paymorz - Financial Dashboard Landing Page

A production-ready React + TypeScript landing page built from a Figma design. This project features a pixel-perfect implementation with smooth animations, responsive design, and modern UI/UX patterns.

## 🚀 Features

- ✅ **Pixel-Perfect Design**: Faithfully recreated from Figma with exact spacing, colors, and typography
- ✅ **Fully Responsive**: Works seamlessly across mobile, tablet, desktop, and large screens
- ✅ **Smooth Animations**: Framer Motion powered animations for delightful interactions
- ✅ **TypeScript**: Full type safety with comprehensive interfaces
- ✅ **Modern Stack**: Vite + React + TypeScript + Tailwind CSS
- ✅ **Accessibility**: Semantic HTML and ARIA attributes
- ✅ **SEO Optimized**: Meta tags and semantic structure
- ✅ **Code Splitting**: Lazy loading and optimized bundle size

## 📋 Prerequisites

- Node.js 18+ and npm/yarn

## 🛠️ Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd figmaToCode_cursor
```

2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🎨 Design System

### Colors

- **Shades**: White (#FFFFFF) to Black (#000000)
- **Grey Scale**: 100-900 for UI elements
- **Accent**: Gradient from peach to purple (#F6DEC6 → #A2DCFE)
- **Status**: Success (#27A963), Error (#E45757), Warning (#FFB442)

### Typography

- **Font**: Poppins (300, 400, 500, 600, 700)
- **Sizes**: h1 (16px) to h5 (10px) with consistent line heights

### Spacing

- Consistent spacing scale using Tailwind's spacing utilities
- Card padding: 20-30px
- Section gaps: 16-30px
